# Build a Large Language Model (From Scratch)

这是 Sebastian Raschka 的同名图书配套代码仓库，另有按书籍章节编排的视频课程。七个主章节用 PyTorch 从文本处理、注意力机制和 GPT 模型实现，逐步走到预训练、分类微调与指令微调；附录补充 PyTorch 基础、练习解答和训练方法。

## 课程目录

| 课次 | 课程 | 内容介绍 |
| --- | --- | --- |
| 01 | 理解大语言模型 | 认识大语言模型的基本概念，以及从零构建模型的整体流程。 |
| 02 | 处理文本数据 | 学习分词、文本嵌入和数据加载，为模型准备训练文本。 |
| 03 | 编写注意力机制 | 从自注意力入手，实现因果注意力和多头注意力。 |
| 04 | 从零实现 GPT 模型 | 将注意力模块等组件组合成可生成文本的 GPT 模型。 |
| 05 | 使用无标签数据预训练 | 训练 GPT 模型预测后续文本，并用训练后的模型生成文本。 |
| 06 | 面向文本分类进行微调 | 将预训练模型改造成分类器，并在文本分类任务上微调。 |
| 07 | 微调模型以遵循指令 | 准备指令数据、微调模型生成符合指令的回答，并评估结果。 |
| 附录 A | PyTorch 入门 | 学习实现前面章节代码所需的 PyTorch 基础。 |
| 附录 B | 参考文献与延伸阅读 | 查看各章引用的资料和后续阅读资源。 |
| 附录 C | 练习解答 | 对照书中练习的解题思路与代码答案。 |
| 附录 D | 改进训练循环 | 为训练流程加入学习率调度、梯度裁剪等改进。 |
| 附录 E | 使用 LoRA 进行参数高效微调 | 学习以 LoRA 方式微调模型，减少需要更新的参数。 |
