# Generative AI for Beginners

这是面向生成式 AI 应用开发的入门课程；第 00 课用于配置环境，之后是 21 节正式课程。课程包含概念讲解（Learn）和动手构建（Build），部分课程配有 Python、TypeScript 代码示例。

## 课程目录

| 课次 | 课程 | 内容介绍 |
| --- | --- | --- |
| 00 | 课程环境配置 | 配置运行课程示例所需的开发环境。 |
| 01 | 生成式 AI 与大语言模型简介 | 了解什么是生成式 AI，以及大语言模型如何工作。 |
| 02 | 探索和比较不同的大语言模型 | 学习根据具体用途选择合适的模型。 |
| 03 | 负责任地使用生成式 AI | 了解如何负责任地构建生成式 AI 应用。 |
| 04 | 提示工程基础 | 通过实践掌握编写提示词的基本方法。 |
| 05 | 创建高级提示词 | 运用提示工程技巧改善模型的输出。 |
| 06 | 构建文本生成应用 | 使用 Azure OpenAI 或 OpenAI API 构建文本生成应用。 |
| 07 | 构建聊天应用 | 学习构建聊天应用并将其集成到其他应用中的方法。 |
| 08 | 构建搜索应用 | 利用文本嵌入搜索数据，构建搜索应用。 |
| 09 | 构建图像生成应用 | 动手开发图像生成应用。 |
| 10 | 使用低代码工具构建 AI 应用 | 使用低代码工具开发生成式 AI 应用。 |
| 11 | 通过函数调用集成外部应用 | 了解函数调用及其在应用集成中的用途。 |
| 12 | AI 应用的用户体验设计 | 将用户体验设计原则用于生成式 AI 应用。 |
| 13 | 生成式 AI 应用安全 | 认识 AI 系统面临的威胁与风险，并学习防护方法。 |
| 14 | 生成式 AI 应用生命周期 | 了解管理大语言模型生命周期和 LLMOps 所需的工具与指标。 |
| 15 | 检索增强生成与向量数据库 | 使用 RAG 框架和向量数据库构建检索应用。 |
| 16 | 开源模型与 Hugging Face | 使用 Hugging Face 上的开源模型构建应用。 |
| 17 | AI 智能体 | 使用 AI 智能体框架构建应用。 |
| 18 | 大语言模型微调 | 了解微调是什么、为什么需要微调，以及如何进行微调。 |
| 19 | 使用小语言模型构建应用 | 了解使用小语言模型开发应用的优势。 |
| 20 | 使用 Mistral 模型构建应用 | 了解 Mistral 系列模型的特点和差异。 |
| 21 | 使用 Meta 模型构建应用 | 了解 Meta 系列模型的特点和差异。 |
